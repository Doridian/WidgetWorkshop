Widget Workshop

A Mad Scientist's Laboratory. Maxis' 1995 gadget-building toy, ported to Rust, playable in your browser.

Play in the browser Download

How to play

Get the CD

This site has no game data. The Mac/PC CD is on the Internet Archive as a zip; unzip it for the .iso.

Widget Workshop on archive.org (zip, 196 MB)

Open the game

Open it, choose the .iso and press Start. The game reads it in your browser; nothing is uploaded.

Build

The browser keeps the CD and the widgets you save, so next time it starts straight away. Drag a .wgt onto the game to open it; the File menu downloads widgets.

Download

The native builds ask for the CD image the first time they start, then remember it.

All releases are on GitHub. The macOS app is signed ad hoc only: open it the first time with a right click, Open.

What's in it

  • The editor: the parts tray, wiring, the worksheets, undo, the parts' own settings dialogs.
  • The parts run as in the original: logic, numbers, science, sound and time, input and output.
  • The puzzles, saving and loading widgets in the original's .WGT format, and the help.
  • Sound, and recording through the microphone.
  • A resizable window with scaling, in the browser with WebGPU or WebGL2.

About

This is a non-matching decompilation of WIDGET.EXE, rewritten in Rust: it behaves like the original but doesn't share its code. The source is on GitHub, and its browser notes list the page's options.

An unofficial port of the 1995 Maxis game. Widget Workshop is a trademark of its owners; no game data is included.
